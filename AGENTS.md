# Deployment instructions

- After completing and validating any requested change to this website, commit the relevant files and push the `main` branch to `origin`.
- Treat a successful push to `origin/main` as the normal completion condition because GitHub Pages deploys this repository.
- Do not leave a completed website change only in the local repository unless the user explicitly asks for a local-only change.
- If GitHub authentication or deployment fails, preserve the local commit and clearly report the blocking error.
- Never force-push or rewrite published history.
